# Agent kit

This repo is portable scaffolding for AI-assisted work — skills, agent instructions, and plans you can clone or symlink onto any machine. Not project-specific domain work.

## Skills

Portable skills live in `skills/`. Each skill is a folder with a `SKILL.md`.

Kit skills end the frontmatter `description` with `- BkS👨‍💻` (hover tooltip). Not needed in the body.

Install onto this machine (Cursor whole-dir + per-skill Claude/Codex links):

```bash
./sync.sh
```

See the repo README for details and the Cloud Agents caveat.
